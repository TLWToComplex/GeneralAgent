# Skill 使用示例（对话调用）

以下示例用于触发并正确使用 `table-image-analysis-report` skill。

## 示例 1：基础流程

用户：
- 我上传了一张酒店费用表，请帮我识别成表格并分析每个人与平均酒店价格的差异。

期望行为：
1. 进入 `collect_input`，确认币种/日期格式/是否自动纠错
2. 执行 OCR 与布局分析
3. 输出结构化表格
4. 在分析前给出可确认的纠错建议
5. 计算均值、偏差、异常并生成报告

## 示例 2：多页图片

用户：
- 我上传了 3 张连续页面的费用表，请合并后做异常分析。

期望行为：
1. 使用 `page_index` 分页处理
2. 合并列名并记录 `merge_warnings`
3. 默认选择主表并保留次表
4. 输出合并后的分析报告

## 示例 3：低置信人工确认

用户：
- 这张图有点模糊，你尽量识别。

期望行为：
1. 若 `confidence_score < 0.65`，停止自动推进
2. 返回人工确认模板（关键字段候选值）
3. 等待用户确认/修正/补图后继续

## 示例 4：仅导出结构化结果

用户：
- 不要报告，只给我 markdown 表格和 csv。

期望行为：
1. 仍执行结构化流程
2. 报告可最小化，但必须保证 `final_export` 完整
3. 返回 `markdown_table`、`csv_text`、`json_rows`

## 示例 5：酒店价格专用分析

用户：
- 重点看平均酒店价格、每人的正负偏差、异常人员。

期望行为：
1. 自动识别 `姓名` 与 `酒店价格`
2. 输出总体均值
3. 输出每人 `delta`（正负）
4. 用 z-score 或 IQR 给出异常说明与建议
