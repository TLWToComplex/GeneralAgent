# 酒店价格专用分析模板（可直接套用）

用于 `analyze_data` 与 `generate_report` 阶段，目标是稳定输出：
- 平均酒店价格
- 每个人与平均价格的差异（正负）
- 异常值判定

## 字段识别优先级

1. 人员维度：`姓名`/`人员`/`员工`/`旅客`
2. 数值指标：`酒店价格`/`住宿费用`/`房费`
3. 可选维度：`城市`/`日期`/`酒店等级`

## 计算逻辑

1. 统一货币与数值格式（去货币符号、去千分位）
2. 计算总体均值：
   - `overall_mean_price = mean(酒店价格)`
3. 计算个人偏差：
   - `delta_i = 个人均价 - overall_mean_price`
4. 判定异常（择一）
   - z-score: `|z| > 1.5`（样本少时可降到 1.2）
   - IQR: `x > Q3 + 1.5*IQR` 或 `x < Q1 - 1.5*IQR`

## 输出要求

- 关键发现至少包含：
  - 总体均价
  - 偏高 Top3
  - 偏低 Top3
- 异常说明至少包含：
  - 异常对象
  - 异常幅度
  - 可能原因（城市、时段、酒店级别）
- 建议至少包含：
  - 预算阈值建议
  - 复核名单
  - 后续采集字段建议

## 图表建议

1. 柱状图：人员 vs 平均酒店价格（对比个体差异）
2. 箱线图：酒店价格分布（识别异常）
3. 折线图（若有日期）：时间 vs 酒店价格（趋势）

## 最小可交付报告模板

- 摘要：一句话总结均价与整体离散程度
- 关键发现：3-5 条
- 异常说明：逐条列出对象、数值、规则
- 行动建议：预算、审批、数据治理
