## G01.0403 规范摘要

### 2.1 页面设置
| 项目 | 要求 | GA-spec.json 对应值 |
|------|------|-------------------------|
| 纸张 | A4 (210mm × 297mm) | `page.size: "A4"` |
| 上边距 | 2.54 cm | `page.margin_top_cm: 2.54` |
| 下边距 | 2.54 cm | `page.margin_bottom_cm: 2.54` |
| 左边距 | 1.91 cm | `page.margin_left_cm: 1.91` |
| 右边距 | 1.91 cm | `page.margin_right_cm: 1.91` |
| 页眉距边界 | 1.5 cm | `page.header_distance_cm: 1.5` |
| 页脚距边界 | 1.75 cm | `page.footer_distance_cm: 1.75` |

### 2.2 字体要求
| 位置 | CJK 字体 | Latin 字体 | 字号 |
|------|----------|-----------|------|
| 封面标题 | 宋体 | Times New Roman | 二号 (22pt) |
| 封面信息 | 宋体 | Times New Roman | 四号 (14pt) |
| 正文 | 宋体 | Times New Roman | 小四 (12pt) |
| 页眉 | 宋体 | Times New Roman | 五号 (10.5pt) |
| 页脚/页码 | 宋体 | Times New Roman | 小五 (9pt) |
| 表格内容 | 宋体 | Times New Roman | 小四 (12pt) |
| 表格表头 | 宋体（加粗） | Times New Roman | 五号 (10.5pt) |

> **核心原则**: 全文（含封面、页眉页脚、表格）统一使用 宋体 + Times New Roman，无其他字体。

### 2.3 行距与缩进
| 项目 | 要求 | spec 对应值 |
|------|------|------------|
| 正文行距 | 1.5 倍行距 | `spacing.body_line_spacing_pt: 1.5` |
| 首行缩进 | 2 字符 | `spacing.first_line_indent_chars: 2` |
| 段前/段后 | 0 行 | `spacing.paragraph_before_pt: 0` |
| 页眉行距 | 单倍行距 | `spacing.header_line_spacing_pt: 1.0` |

### 2.4 对齐方式
| 位置 | 对齐 | spec 对应值 |
|------|------|------------|
| 封面内容 | 居中 | `alignment.cover_*: "center"` |
| 正文 | 两端对齐 | `alignment.body: "both"` |
| 页眉 | 居中 | `alignment.header: "center"` |
| 页脚 | 居中 | `alignment.page_number: "center"` |

### 2.5 特殊区域
| 区域 | 识别关键词 |
|------|-----------|
| 封面 | `titlePg` 属性 / 前 N 个居中段落 |
| 目录 | "目录"、"目  录" |
| 修订记录 | "修订记录"、"版本历史"、"修订历史"、"Revision History" |

## Skill 映射说明

### 字体映射规则

Skill 通过 `set_run_font_xml()` 设置 XML 级别的字体：
- `w:eastAsia` → CJK 字体（宋体）
- `w:ascii` / `w:hAnsi` → Latin 字体（Times New Roman）
- `w:cs` → 复杂脚本字体（Times New Roman）

对于纯英文/数字 run（如文件编号 "DH2007003CMP V1.8"），`w:eastAsia` 也被设为 Times New Roman，避免从段落级继承错误的 CJK 字体。

### 表格处理

`_apply_all_tables_format()` 处理所有表格：
- 表头行：`revision_header` 字体对（宋体 + TNR，10.5pt，加粗）
- 表体行：`body` 字体对（宋体 + TNR，12pt）
- 统一加单线边框 + 表头灰色背景

### 校验覆盖（v0.4，16项）

```
page_margins      → 页面边距（上/下/左/右）
page_size         → 页面尺寸（A4）
cover_fonts       → 封面字体（标题/副标题/信息行）
body_fonts        → 正文 CJK + Latin 字体
heading_fonts     → 标题字体（h1-h4）
revision_section  → 修订记录标题字体
toc_section       → 目录标题字体
line_spacing      → 正文行距
paragraph_alignment → 段落对齐
first_line_indent → 首行缩进
page_numbers      → 页码存在性
table_borders     → 表格边框
table_header_fonts → 表头字体
table_body_fonts  → 表体字体 ✨v0.4新增
header_fonts      → 页眉字体 ✨v0.4新增
footer_fonts      → 页脚字体 ✨v0.4新增
```
