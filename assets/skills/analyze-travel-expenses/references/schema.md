# 字段与输出

| 角色 | 候选字段 |
|---|---|
| 唯一键 | 消费记录唯一值、订单号 |
| 部门 | 报账部门、费用承担部门 |
| 人员 | 乘机人、乘机人编号 |
| 消费类型 | 消费类型（忽略字段名前后空格） |
| 金额 | 实收实付、企业支付金额、票面价 |
| 日期 | 出发时间、预订时间、报销完成日期 |
| 住宿 | 住宿天数、住宿标准、地区类型、等级 |
| 交通 | 出发地、到达地、折扣率(%)、退改签类型 |
| 流程 | 报销状态、对账状态、是否清账、明细状态 |

`analysis.json` 必须包含概览、消费类型、部门、月份、人员、路线、住宿合规、折扣分布和流程状态。

`validation.json` 必须包含扫描文件数、原始行数、接受行数、重复键数、空键数、字段缺失和金额平衡差异。
