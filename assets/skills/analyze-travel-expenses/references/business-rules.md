# 业务口径

- 默认金额字段按“实收实付 → 企业支付金额 → 票面价”的优先级选择，不在同一行叠加这些字段。
- 退款、退票和冲销金额保留负号。展示“消费规模”时可另算绝对金额，但必须与净额分开标注。
- 默认使用“消费记录唯一值”去重；缺失时退化到“订单号”。仅在键非空时去重，空键记录全部保留。
- 默认部门使用“报账部门”；用户明确要求费用归属时改用“费用承担部门”。
- 住宿单晚价格 = 净金额 / 住宿天数。仅对金额、天数和标准均大于 0 的住宿记录计算标准使用率。
- 退款记录不参与住宿达标率，但计入净额。
- 折扣率仅用于机票和火车票；0 或空值归入“未提供”，不能默认等同于八折以上。
- 同一订单可能包含出票、退票和改签多条消费记录，禁止仅按订单号无条件保留一条。
- 总体净额必须等于按消费类型、部门和月份任一完整分组后的金额合计，允许误差不超过 0.01 元。
- “保障部门类别”默认按配置项“部门统计字段”解释，默认值为“报账部门”。
- 酒店等级缺失时归为“未指定”。
- 价格偏离统一基于有效住宿记录的单晚住宿费；部门偏离基准为全部有效住宿的加权单晚均价。
- “预订在前但价格更低”按同一城市、同一入住日期比较；早订订单的预订时间必须严格早于晚订订单。
- “同城10天偏高”按入住日前9天至入住日的同城有效订单形成批次，订单单晚价格高于批次均价即标记；使用“同城高价判定倍数”调整阈值。
- 协议住宿酒店统一定义为“服务费大于 0”；非协议住宿酒店统一定义为“服务费等于 0”。服务费为空时不参与协议属性统计。
